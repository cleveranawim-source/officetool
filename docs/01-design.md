# 시수핏 — 설계와 결정 사항 (v0.2)

## 1. 확정된 결정

| 항목 | 결정 |
|---|---|
| 형태 | 웹앱 + Apps Script 하이브리드. 같은 HTML 한 파일이 브라우저 단독으로도, Apps Script 웹앱 안에서도 돈다 |
| 학사일정 | 구글 캘린더(AI 교무실)가 원본. Apps Script로 직접 읽고, 단독 실행 때는 .ics 파일 |
| 시간표 | "전체 학반 시간표" 시트를 붙여넣기 또는 시트 주소로 읽음. 새 학기에도 같은 형식이면 그대로 사용 |
| 규모 | 3개 학년 × 10반 = 30학급, 45분 수업, 월6·화7·수6·목7·금6 교시 |
| 과목 단위 | 시간표에 적힌 과목명 그대로 (영A·영B, 과A·과B 등 분반 과목도 따로) |
| 교시 표기 규칙 | 제목 끝 `n-m` = n~m교시, 끝 숫자 한 자리 = 그 교시 (`함께하는 삶1`) |

## 2. 시간표 구조 분석 (2026-2학기 원본 기준, 교사 실명은 저장소에 두지 않음)

- 한 학년 안에서는 **모든 반의 과목별 주당 시수가 같다**. → 반간 시수 차이는 전부 "그 과목이 어느 요일·교시에 있느냐"에서 생긴다.
- 주당 32칸 = 교과 31 + 창체 1 (수요일 6교시 전교 공통 창체).
- 주 1시간 과목(종교, 진로, 영B, 체B, 운동, 1학년 음악 등)은 한 번만 걸려도 비율상 손실이 크다.
- 미술은 2교시 연속(블록)이라 하루가 빠지면 2시간이 한꺼번에 빠진다.
- 운동(스포츠) 강사 수업은 특정 요일(화·목·금)에 몰려 있어, 그 요일 행사에 취약하다.
- 원본 점검에서 **교사 중복 배정 1건**이 자동으로 발견됨 (같은 교사가 같은 시간 두 반). 시간표 원본 수정 필요.

## 3. 계산 규칙

1. 학기 중 평일마다, 반마다 그날의 요일 시간표를 편다 (`요일 교체` 일정이 있으면 그 요일로).
2. 우선순위: 휴업·방학 > 전일 행사 > 시험(설정에 따라) > 교시 대체.
3. 대체되지 않은 교시는 그 과목 시수 +1, 대체된 교시는 "빠진 교시" 기록(날짜·교시·일정)으로 남긴다 → 화면의 모든 숫자에 근거가 붙는다.
4. **편제 목표** = 주당 시수 × 기준 주수(기본 17주).
5. **체크포인트** = 정기고사 첫날. 그 전날까지 누적 시수로 학년 안 반간 격차(최다 − 최소)를 본다.

## 4. 보완 제안 알고리즘

- 점수 = 4 × Σ(편제 대비 부족)² + Σ(체크포인트·학기말 반간 격차)². 작을수록 좋다.
- 후보
  - **요일 교체**: 기준일 이후, 아무 일정도 없는 날을 다른 요일 시간표로 운영. 전교가 같은 요일 시간표를 쓰므로 교사 겹침이 없다.
  - **교시 이동**: 하루짜리 부분 교시 행사(`함께하는 삶1` 등)를 다른 교시로 옮김.
- 가장 점수를 많이 줄이는 후보부터 최대 4개를 차례로 고른다(탐욕법). 30학급 실데이터 기준 0.5초 안팎.
- **해를 끼치는 안은 제외**: 어느 시험 기준점(학기 전체 포함)이든 학년·과목 최대 반간 격차가 늘거나, 편제 부족 시수가 늘면 점수가 좋아져도 후보에서 뺀다.
- **요일 교체는 같은 모양의 요일끼리만**: 모든 반에서 교시 수와 창체 수가 같은 요일끼리 (하교 시간·창체 시수가 바뀌지 않음).
- 교시 이동은 다른 일정과 겹치는 교시, 옮길 수 없는 일정(듣기평가·종업식 등)을 제외한다.
- 제안은 "미리 적용"으로 켜서 모든 화면을 다시 계산해 본 뒤, 캘린더에 등록한다.

## 5. 화면

| 화면 | 역할 |
|---|---|
| 한눈에 보기 | 수업일수, 다음 시험 D-day, 최대 반간 격차, 편제 부족 / 먼저 볼 것 / 요일별 결손 / 반×과목 히트맵 |
| 학사일정 | 달력 + 일정 분류 확인·수정 |
| 반·과목 | 학년별 히트맵 두 가지(반간 격차, 편제 대비) |
| 시험 대비 | 과목마다 반별 누적 시수를 점으로, 격차 큰 순 |
| 교사 시수 | 주당 시수, 요일 분포, 학기 계획, 빠진 교시 |
| 보완 제안 | 제안 카드(미리 적용), 캘린더 등록, 보강 필요 목록 |
| 데이터·설정 | 캘린더·시간표 연결, 학기·기준 주수·시험 인정, 시간표 점검 |

디자인: 칠판 녹색을 포인트로, 녹색 기운의 뉴트럴. 부족=빨강, 초과=파랑만 의미색으로 쓴다. 라이트/다크 모두 지원.
