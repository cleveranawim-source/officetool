# 교무업무 통합 웹앱과 학사일정 짜기 — 설계 초안

> 상태: v1 구현. 앱 이름 **교무핏** (시수핏은 "시수 점검" 탭).
>
> 결정 (2026-09-30): AI는 **규칙 엔진 + AI 보조**, 공동 수정은 **구글 시트**, 통합 앱은 **새 이름**.

## 1. 그림

하나의 웹앱 안에 교무 업무 도구가 탭으로 들어간다. 도구들은 **학교 정보·시간표·학사일정을 한 곳에서 같이 쓴다.**

```
┌ 교무 통합 웹앱 ───────────────────────────────────────────┐
│  [학사일정 짜기]  [시수 점검(시수핏)]  [다음 도구 …]           │
│                                                          │
│  공용 데이터: 학교 정보 · 시간표 · 학사일정(초안/확정) · 공휴일 표  │
└──────────────────────────────────────────────────────────┘
```

- **학사일정 짜기**에서 만든 초안이 바로 **시수 점검**으로 들어가, 일정을 짜는 동안 반·과목 시수 균형을 같이 본다.
  (지금은 확정된 일정을 나중에 점검하지만, 짜는 단계에서 막는 것이 훨씬 싸다.)
- 지금의 시수핏 코드(계산 엔진, 가져오기, 분류 규칙, NEIS)는 그대로 공용 부품이 된다.

## 2. 학사일정 짜기: 흐름

1. **작년 일정 넣기**: 구글 캘린더(.ics), 시트(목록형·달력형), NEIS — 이미 읽을 수 있는 형식 전부
2. **새 학년도 기본값**: 개학일, 방학식·종업식 날, 방학 기간, 새해 공휴일(자동), 선거일 등 특별 휴일
3. **1차안 자동 생성**: 일정마다 "어떻게 옮겼는지"와 이유가 붙는다
4. **교사 검토·수정**: 달력에서 끌어 옮기기, 충돌·확인 필요 목록부터 처리, 수업일수·시수 균형이 실시간으로 바뀜
5. **내보내기**: 구글 캘린더 등록, 시트(달력형) 파일, .ics

## 3. 1차안 엔진: 일정마다 "기준"을 찾아 옮긴다

날짜를 그대로 1년 미루면 요일이 어긋나고, 364일 미루면 달이 어긋난다. 일정마다 무엇에 맞춰 잡힌 날인지(기준)를 먼저 알아내고, 그 기준을 새 학년도에서 다시 푼다.

| 기준 | 예 | 새 학년도에서 |
|---|---|---|
| 고정 날짜 | 개교기념일, 법정 기념일 | 같은 날짜. 주말이면 확인 필요로 |
| 학기 경계 | 개학식(첫날), 방학식·종업식(마지막 날), 입학식 | 새 학년도 기본값에서 |
| 몇째 주 무슨 요일 | "4월 마지막 주 월~수 중간고사" | 같은 달 같은 주차·요일 |
| 다른 일정 기준 | 시험 다음 날 체육대회, 시험 1주 전 교과협의회 | 기준 일정을 먼저 옮긴 뒤 같은 간격 |
| 반복 | 매주 월 교직원예배, 매월 부장회의, 학급자치 | 새 달력에서 다시 펼치고 휴일은 건너뜀 |
| 징검다리 휴업 | 공휴일 사이 평일의 재량휴업일 | **작년 날짜를 옮기지 않고** 새해 징검다리 후보를 다시 찾음 |

기준을 찾는 방법(규칙): 이름 낱말(개학·방학·시험·개교기념), 작년 날짜와 공휴일·학기 경계·다른 일정 사이 간격, 같은 이름의 반복 간격.

### 충돌 처리

- 옮긴 날이 공휴일·방학·다른 전일 행사와 겹치면: 같은 주 안 가까운 평일 → 앞뒤 주 순으로 후보를 만들고 **"확인 필요"** 로 표시 (자동 확정하지 않음)
- 여러 날짜 일정(수련회 3일, 시험 3일)은 통째로 옮긴다
- 시험 기간에는 전일 행사·특별교육을 두지 않는다

### 점검 (초안 옆에 늘 보이게)

- **수업일수 190일 이상** (초·중등교육법 시행령 제45조; 학교장 재량 감축 범위는 설정)
- 학기별 수업일수, 요일별 수업일수 균형 (한 요일만 크게 빠지지 않게)
- 시험 전 반간 시수 격차, 편제 부족 — 지금의 시수핏 계산 그대로

## 4. AI의 몫 — 결정: 규칙 엔진 + AI 보조

| 방식 | 장점 | 단점 |
|---|---|---|
| 규칙 엔진만 | 무료, 학교 자료가 밖으로 안 나감, 결과를 설명할 수 있음 | 이름이 애매한 일정, 자유 서술 요청("올해는 수련회를 5월로")은 못 알아들음 |
| 규칙 + 언어 모델 | 애매한 일정의 기준 판단, 자유 요청 반영, 바뀐 이유를 자연스러운 문장으로 | API 키·비용, 일정 이름이 외부로 나감 |

**규칙 엔진이 1차안을 만들고, 언어 모델은 "확인 필요" 일정 판단과 자유 요청 반영만 돕는다.** 모델이 없어도 앱은 완전히 돈다.

구현 (v1):
- 교사 본인의 Anthropic API 키로 브라우저에서 직접 호출 (키는 그 브라우저에만 저장, 설정 파일·시트·공용 저장에 넣지 않음)
- 보내는 것: 새 학년도 학기, 평일 공휴일, 1차안 일정(이름·날짜·종류·학년·상태·기준·작년 날짜·후보), 매주 반복 일정 요약, 교사의 요청 글. 교사 이름·시간표는 보내지 않음
- 받는 것: 구조화 출력(JSON 스키마)으로 옮기기·더하기·빼기 목록과 요약
- 제안마다 규칙 검사(없는 번호, 주말·공휴일, 방학 중 수업 일정, 날 수 변경) → 통과한 것만 체크, 교사가 고른 것만 적용
- 모델 기본값: 가장 최신 Opus, 노력 수준 medium, 안전 분류기 거절 시 서버 대체 모델(fallbacks: default)

## 5. 함께 고치기 — 결정: 구글 시트

- 구글 시트: 학교 드라이브에 초안 시트를 만들어 여럿이 동시에 고침 (Apps Script)
- 구글 캘린더: 초안용 캘린더를 따로 만들어 교사들이 캘린더에서 고침
- 앱 안 + 파일 공유: 서버 없이 가장 단순하지만 동시 수정은 안 됨

구현 (v1): 시트 한 장에 `날짜 | 끝 날짜 | 일정 | 상태 | 근거 | 작년 날짜 | 번호`. Apps Script에서는 "구글 시트로 만들기"(확인 필요 줄 강조) → 공유 → "시트에서 다시 읽기". 브라우저만 쓸 때는 .csv로 내려받아 드라이브에서 시트로 열고, 고친 뒤 .xlsx로 받아 올린다. "번호"로 원래 일정과 맞추고, 번호 없는 줄은 새 일정, 사라진 번호는 뺀 일정으로 본다.

## 6. 공휴일 표

- 새 학년도(3월~다음 해 2월) 공휴일이 필요하다. 음력 공휴일(설·추석·부처님오신날)과 대체공휴일 규칙 때문에 해마다 표를 넣고, 관리자가 확인할 수 있게 한다.
- 선거일·임시공휴일은 발표 뒤 직접 넣는다.

## 8. 시간표 교체 (결보강 포함) — 초안

결보강은 따로 만들지 않고 시간표 교체의 한 경우로 넣는다. 교사가 빠지는 수업을 채우는 방법은 **교체**(다른 교사 수업과 맞바꾸기, 시수 유지)와 **보강**(다른 교사가 들어감, 원래 수업은 빠짐) 두 가지이고, 둘 다 같은 조건 검사를 거친다.

| 경우 | 입력 | 결과 |
|---|---|---|
| 결보강 | 교사·날짜·교시(출장, 연가, 연수) | 교체안 우선, 안 되면 보강 교사 후보 |
| 수업 맞바꾸기 | 두 수업 또는 "이 수업을 다른 날로" | 가능한 상대 수업과 되돌릴 날 |
| 행사 교시 이동 | 행사 교시 | 지금의 보완 제안(요일 교체·교시 이동)을 반 단위로 |

학교마다 다른 조건(설정으로 켜고 끄고 순서를 정함): 같은 과목·같은 학년 교사 우선, 담임 우선, 교사 하루 최대 시수, 연강 제한, 보강 시수 누적 균형, 교사별 불가 시간(부장 회의 등), 교체 후 원래대로 되돌리는 기한, 시험 전 주 교체 금지, 반간 시수 격차를 늘리지 않을 것.

**베타 (2026-09-30)**: 결보강 찾기를 먼저 넣었다(`engine/swap.ts`, `ui/SwapApp.tsx`).
- 빠지는 선생님·날짜·교시·사유 → 수업마다 교체 후보(같은 반 다른 수업과 맞바꾸기, 같은 주 또는 다음 주까지) 최대 3개, 보강 후보 최대 5개
- 조건: 범위, 하루 최대 수업, 최대 연강, 같은 과목·담임·같은 학년 우선, 보강 몰림 방지(누적 횟수)
- 고른 결보강은 다음 찾기에 반영(같은 선생님 이중 배정 방지), 안내문 복사, "확정하고 기록"으로 보강 누적
- 학사일정의 휴업·방학·시험·전일 행사 날은 교체 대상에서 뺌
- 한계: 요일별 기본 시간표 기준(그날의 요일 교체·교시 옮김 미반영), 수업 맞바꾸기·행사 교시 이동 화면은 아직, 기록은 이 브라우저에만

필요한 자료: 교사가 들어 있는 시간표(엑셀). NEIS 시간표에는 교사가 없어 쓸 수 없다. 교체·보강 기록이 쌓이면 시수 점검이 실제 수업 기준으로 계산한다.
