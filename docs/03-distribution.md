# 시수핏 — 전국 학교 배포 전략 (초안)

목표가 "우리 학교 도구"에서 **"어느 학교든 쓰는 도구"**로 바뀌었다. 무엇이 달라지는지 정리한다.

## 1. 한 학교용과 모든 학교용의 차이

| 영역 | 한 학교용 (지금까지) | 모든 학교용 |
|---|---|---|
| 배포 | 학교 계정 Apps Script, 도메인 한정 | 누구나 주소 하나로 바로 사용, 설치·가입 없음 |
| 시간표 입력 | 우리 학교 "전체 학반" 시트 형식 | 학교마다 다른 형식 → 가져오기 마법사(열 지정), 엑셀 파일 업로드 |
| 학사일정 입력 | 구글 캘린더 | 구글 캘린더 / iCal / 구글 시트 달력형 / 엑셀 / NEIS 학사일정 |
| 일정 제목 규칙 | 우리 학교 표기 | 학교마다 다름 → 키워드·표기 규칙을 화면에서 편집, 학교별 규칙 파일 |
| 학교급 | 중학교 3학년×10반, 45분 | 초·중·고, 학급 수·교시 수·기준 주수 모두 설정값 |
| 개인정보 | 한 학교 내부 | 교사 실명은 선택 입력, 데이터는 학교 밖으로 나가지 않게 |
| 업데이트 | 제가 직접 올림 | 모든 사용자가 자동으로 최신 버전 |
| 지원 | 직접 대화 | 사용 안내, 예시 데이터, 문의 창구 |

## 2. 권장 구조: "서버 없는 웹앱" + 선택형 구글 연동

```
[누구나]  https://…/sisufit   ← 정적 웹앱 (GitHub Pages 등, 무료)
            │  모든 계산은 브라우저 안에서. 서버에 아무것도 보내지 않음
            │  데이터는 내 브라우저에 저장 + "학교 설정 파일" 내보내기/가져오기
            │
            ├─ 시간표: 엑셀/시트 파일 올리기 · 붙여넣기 · (NEIS 시간표)
            ├─ 학사일정: iCal 주소/파일 · 구글 시트 달력 · (NEIS 학사일정)
            └─ (선택) 구글 연동: 학교 안에서 설정 공유, 캘린더 직접 읽기·등록
                       └ 구글 시트 템플릿 "사본 만들기" + Apps Script 라이브러리
```

- **왜 서버가 없나**: 학교는 외부 서버에 교사·학생 정보를 올리는 것을 꺼린다. 브라우저 안에서만 계산하면 개인정보 문제를 설명할 필요가 거의 없고, 운영비도 0원이다.
- **NEIS 교육정보 개방 포털**: 전국 학교의 학사일정과 학급 시간표를 학교 이름 검색만으로 가져올 수 있다. 첫 화면을 "학교 검색"으로 시작할 수 있어 온보딩이 가장 쉬워진다. 단, 교시 단위 특별교육은 학교 캘린더에만 있으므로 보조 입력으로 쓴다. (API 키 발급·브라우저 직접 호출 가능 여부 확인 필요)
- **구글 연동은 선택**: 구글 워크스페이스 학교는 템플릿 사본 하나로 학교 공용 설정과 캘린더 등록까지. 업데이트는 Apps Script 라이브러리로 배포자가 한 번 올리면 모든 사본에 반영.

## 3. 단계

| 단계 | 내용 |
|---|---|
| 1. 일반화 | 학교급·학급 수·교시 수·기준 주수 설정, 규칙 편집 화면, 시간표 가져오기 마법사(엑셀 업로드 포함), 구글 시트 달력형 학사일정 읽기 |
| 2. 공개 웹앱 | 정적 호스팅, 첫 화면 온보딩(학교 정보 → 시간표 → 학사일정 → 규칙 확인), 예시 학교로 둘러보기, 설정 파일 내보내기 |
| 3. 시범 학교 | 표기 방식이 다른 학교 3~5곳 데이터로 자동 분류 정확도 확인 |
| 4. 구글 템플릿 | 사본 만들기 템플릿 + 라이브러리 업데이트 |
| 5. 확산 | 교사 커뮤니티 공유, 사용 안내 영상, 문의 창구 |

## 4. 학교급별 고려 사항

- **중학교**: 학기당 17주 기준, 자유학기·동아리·스포츠클럽, 분반(A/B) 과목. 지금 엔진 그대로 적용.
- **고등학교**: 고교학점제로 과목 이수 기준(수업 횟수의 2/3 출석, 학점당 수업 횟수)이 있어 결손 확인 수요가 더 크다. 선택과목은 반 대신 "수강 그룹" 단위로 계산해야 한다.
- **초등학교**: 40분, 학년군(2년) 단위 시수, 담임 수업 중심. 반간 격차보다 교과별 연간 시수 확인이 핵심.

## 5. 결정 사항 (2026-09)

| 항목 | 결정 |
|---|---|
| 대상 학교급 | 중학교 먼저 → 고등학교 → 초등학교 |
| 배포 형태 | 직관적인 공개 웹앱 (GitHub Pages, 서버 없음) |
| 운영 | 오픈소스(MIT) 공개, 교육청 제안 |
| 시범 학교 | 표기 방식이 다른 학교 자료를 직접 모아 검증 |

## 6. 지금 구현된 것 (v0.3)

- 시작 화면 → 4단계 설정(학교 → 시간표 → 학사일정 → 확인) → 결과
- 시간표: 엑셀(.xlsx)·CSV 올리기, 붙여넣기. "반마다 한 줄"과 "반마다 한 칸(학반별)" 두 배치, 가로(─▷)·세로(│ ▽) 블록 수업 표시, 한 칸에 과목+교사
- 학사일정: 구글 캘린더 .ics, 구글 시트·엑셀 학사일정표(목록형·달력형 자동 판별, .xlsx 올리기·붙여넣기, Apps Script에서는 시트 주소), 법정 공휴일 자동
  - 달력형: `월 | 주 | 월~금 | 토` 머리글, 날짜 줄 아래 일정 줄(여러 줄), 칸 안 줄바꿈, ♥1 같은 표시, 달·해 바뀜, 한 시트에 이어 붙인 학기 표, 날짜 값 칸
- 교사 이름을 "국어1"처럼 바꿔 저장하는 선택
- 학교별 일정 읽기 규칙 편집, 학교 설정 파일 저장·불러오기(학교 안 공유)
- 예시 학교로 둘러보기 (익명화한 실제 중학교 시간표)
- GitHub Actions: 테스트 → 빌드 → GitHub Pages 자동 배포
